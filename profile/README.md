# barkOS
- Arch Linux, but with a friendlier bite

**barkOS** is a Linux distribution designed to make Linux accessible to everyone without sacrificing reliability or control. Featuring a graphical installer and Snapper integration for filesystem snapshots and system rollback, barkOS aims to make system maintenance less intimidating and recovery from mistakes easier. With a focus on usability, stability, and a streamlined desktop experience, barkOS strives to make Linux approachable for beginners while remaining flexible enough for experienced users.

The goal is simple: spend less time fixing your system and more time using it. 
Therefore, our slogan: Arch Linux, but with a friendlier bite
